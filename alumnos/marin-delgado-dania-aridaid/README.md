# MARIN DELGADO DANIA ARIDAID

Esta carpeta es tu espacio de trabajo para subir tus actividades.

## Flujo esperado
1. Crea o cambia a tu rama: `git checkout -b actividadN-marin-delgado-dania-aridaid`
2. Agrega tus archivos dentro de esta carpeta (`alumnos/marin-delgado-dania-aridaid/`).
3. Haz commit con un mensaje claro: `git commit -m "Actividad N: descripcion breve"`
4. Sube tu rama: `git push origin actividadN-marin-delgado-dania-aridaid`
5. Abre un Pull Request hacia `main` desde GitHub y espera revisión del profesor.

No modifiques archivos fuera de esta carpeta.
