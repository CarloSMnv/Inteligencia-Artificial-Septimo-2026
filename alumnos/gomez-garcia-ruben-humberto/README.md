## Flujo esperado
1. Crea o cambia a tu rama: `git checkout -b actividadN-gomez-garcia-ruben-humberto`
2. Agrega tus archivos dentro de esta carpeta (`alumnos/gomez-garcia-ruben-humberto/`).
3. Haz commit con un mensaje claro: `git commit -m "Actividad N: descripcion breve"`
4. Sube tu rama: `git push origin actividadN-gomez-garcia-ruben-humberto`
5. Abre un Pull Request hacia `main` desde GitHub y espera revisión del profesor.

No modifiques archivos fuera de esta carpeta.
