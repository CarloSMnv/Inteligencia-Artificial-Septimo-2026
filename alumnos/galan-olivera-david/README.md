## Flujo esperado
1. Crea o cambia a tu rama: `git checkout -b actividadN-galan-olivera-david`
2. Agrega tus archivos dentro de esta carpeta (`alumnos/galan-olivera-david/`).

5. Abre un Pull Request hacia `main` desde GitHub y espera revisión del profesor.
